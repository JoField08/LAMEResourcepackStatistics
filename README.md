# LAMEResourcepack 2025
This repository provides two different resourcepacks for Minecraft Java 1.21.7. \
The resourcepacks are split in two branches to differentiate them. 
- https://github.com/JoField08/LAMEResourcepackStatistics/tree/LAMEStatistics 
- https://github.com/JoField08/LAMEResourcepackStatistics/tree/LAMEStory

## How do I install the pack?
1. Select the branch in GitHub
2. Download .zip file via 'Code'-button
3. Open you download folder
4. Unzip the downloaded file
5. Transfer the folder in the unziped folder into your resourcepack folder
6. Reload your resourcepacks ingame
